# v0.8 阶段的历史模块

此目录收纳旧的 ChatGPT / Codex 文字路由、网页桥接、配套脚本与测试，以及旧插件安装包。当前工程使用 DeepSeek 文字对话，Codex 仅用于独立生图。

这些文件作为历史资料保留。原目录关系和依赖需结合[整理前快照](https://github.com/Hitachi-Mako71/shuimu-qqbot-dsh-hymemory/tree/fb5d9279bb185ae882bd43455d3746b9ef894ac7)理解；当前安装器不加载本目录。

腾讯官方 QQBot 接入仍是当前受支持方案，代码在 [`app/`](../../app/README.md)，部署见[官方 QQBot 指南](../../docs/deployment/official-qqbot.md)。
