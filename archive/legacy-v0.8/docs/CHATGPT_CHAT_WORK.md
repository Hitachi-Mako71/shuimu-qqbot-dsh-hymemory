# Chat 网页工作通道

控制台提供第三种路由“Chat网页 · 无QQ上下文工作”。需要在 QQ 里交给 ChatGPT 网页处理独立任务时选择它；日常闲聊和需要柚柚记忆时，切回 DeepSeek 或原生 Codex。

## 上下文边界

- 每次只把当前最新的 QQ 用户消息及其附件交给网页；不转发 DSH 会话历史、柚柚人设、Hy Memory、主动日常或其他 QQ 身份资料。
- DSH 仍照常保存 QQ 会话供其自身恢复，但此路由不会把旧消息发送给网页。工作专用 Chat 对话由扩展复用，其中只会有通过此路由提交的工作任务；网页自己的工作对话上下文仍由 ChatGPT 页面保留。
- 该路由跳过记忆召回、记忆写入与陪伴状态更新。Hy Memory 的后台提炼模型仍走配置的 DeepSeek 路由。

## 首次开启与切换

1. 打开控制台 → 对话模型 → 连接 Chat 网页，启动本机桥接并打开连接说明。
2. 在常用 Edge 的 `edge://extensions` 重新加载“柚柚 · Chat 工作桥接”。首次使用时，加载项目 `chat-ui-extension` 文件夹；配对只需在本机输入。
3. 点击扩展“打开专用 Chat 工作对话”，在新标签页确认顶部选择 Chat，再回到扩展确认工作对话。保持专用标签页和浏览器开启；处理任务时让该标签页保持前台可见。后台标签页可能被 Edge 节流，导致网页回复未被桥接回读。
4. 控制台点击“验证所选模型”，实际收到连接成功回复后，选择“Chat网页 · 无QQ上下文工作”并保存，再启动或重启机器人。
5. 需要回到日常聊天时，在控制台选 DeepSeek 或 Codex，保存并重启。切换不会删除另一条路由的会话或记忆。

扩展0.2.1需要 `downloads` 权限，用于把网页生成的附件暂存后回传 QQ；并根据 Chat/Work 切换控件的实际选中状态判断工作页模式。重新加载时 Edge 会显示权限变化；配对信息保存在扩展本机存储中，无需重新输入配对码。

## 文件传递

- QQ 发来的图片、PDF、文本、Office文档、代码文件和ZIP会从腾讯插件下载目录读取，只上传当前任务引用的附件。单个输入附件最多12 MiB，每轮最多6个、合计最多24 MiB。超出大小或不支持的类型会明确失败。
- 网页生成文件后，最终答复需列出实际附件文件名。扩展只处理 ChatGPT 当前回复中匹配的文件链接；桥接把下载内容暂存到 `Downloads/YuzuChatWork/<job-id>`，验证后复制到 `data/memory-workspace/chat-work-output/<job-id>`，并删除下载临时副本。
- DSH 使用腾讯官方 `qqbot_send_file` 把已验证的输出文件发送回当前 QQ 私聊或群。只接受常见图片、文档、代码和ZIP扩展名，单个输出最多24 MiB。工作目录中的副本保留，便于后续查看。
- 文件只交还到发起任务的当前 QQ 会话。模型无法自行指定其他 QQ 用户或群作为目标。

## 本机服务和排错

- `start-qqbot.ps1` 在当前路由为 Chat 工作模式时启动 `127.0.0.1:8767` 桥接；`stop-all.ps1` 会一并停止它。此服务只监听回环地址。
- 控制台中的 Chat 状态应显示“在线 / ready-work”。若未就绪，确认 Edge 扩展已重新加载、工作标签页仍打开且处于 Chat 页面，然后点扩展“刷新状态”和控制台“刷新状态”。
- 上传失败检查最新 QQ 消息是否包含腾讯插件下载的本机附件；回复 `CHAT_UI_FILE_UNAVAILABLE` 表示文件尚未成功下载，`CHAT_UI_FILE_REJECTED` 表示路径不在 QQ 媒体目录内，`CHAT_UI_FILE_TOO_LARGE` 表示超限。
- 网页可回复但文件没回 QQ 时，查看当前 Chat 回复是否带可点击的附件，文件名是否与JSON中的`files`一致，且 Edge 下载目录可用。控制台不会读取或打印网页正文、Cookie或登录令牌。
- 页面改版、登录过期、Chat限额或网络故障会让当前任务返回错误；不会切换到账号授权API或其他收费API。网页通道非流式，等待上限150秒。

2026-10-22本机验收：后台标签页下两次连接探针超时；将Edge工作页保持前台后，探针和QQ文本/附件往返均成功。QQ回传附件`qq-chat-work-check.txt`为12字节，内容正确；测试结束后已恢复DeepSeek默认路由。

## 重要限制

这是对已登录普通 Chat 网页的本机界面操作，不是稳定的官方 Chat API；使用权限、页面可用性、模型选择和套餐限制由 ChatGPT 页面决定。Chat 工作对话本身会保留工作任务之间的网页上下文，因此只在专用工作对话里提交工作内容。如果要完全清空网页端历史，请在扩展中重新打开一个专用工作对话。

本机实际验收前需完成一次 Edge 扩展重新加载和 Chat 工作页确认，再通过控制台验证。源码的上下文隔离、路由检查和文件安全规则可通过本地自动检查；QQ收发和网页登录依赖用户本机页面，不能由纯离线检查替代。
