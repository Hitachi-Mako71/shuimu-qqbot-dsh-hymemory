# 使用普通 Chat 网页

**历史路线，当前已停用。** 用户于2026-10-22明确停止每次新建临时Chat的方案，现运行[官方Work / GPT-6 Luna](WORK_LUNA.md)。不要按本页重新启动网页桥接或重复要求用户配对。以下保留为实现和调试历史；不是推荐的当前部署入口。

## 两条通道

- `chatgpt-chat / browser-chat`：本地浏览器扩展操作真实的普通 Chat 页面；页面内的模型由用户选择，适用 Chat 自身的使用限制。
- `chatgpt-plan`：OpenAI官方账号授权的 Responses 接口。官方明确它使用 Work/Codex 共享用量，不能通过请求参数把计量切到 Chat。

官方资料：[Sign in with ChatGPT](https://learn.chatgpt.com/docs/sign-in-with-chatgpt)、[授权接口的模型调用边界](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)。网页桥接是本项目自建的界面自动化，不是OpenAI提供的普通Chat API，也不保证无限聊天。

## 本机连接

1. 在平常使用的Edge里手动登录 `https://chatgpt.com/`。Google登录若拒绝调试浏览器，使用正常浏览器完成登录；不关闭安全检查、不复制Cookie或令牌。
2. 控制台 → 对话模型 → 连接Chat网页，打开本地配对向导。
3. 在 `edge://extensions` 开启开发人员模式，加载项目中的 `chat-ui-extension` 文件夹。扩展不安装任何第三方云端中转。
4. 在扩展输入向导显示的15分钟配对码，点击配对。配对码只能在本机输入。
5. 点击打开专用临时Chat，在新页确认普通Chat模式，再点击扩展里的确认按钮。保持这个标签页打开。
6. 控制台点击验证Chat回复。只有真实页面回复成功并且状态为Chat/临时对话时，设置后端才允许保存 `chatgpt-chat` 路由。
7. 选择ChatGPT Chat普通网页并保存，重新启动机器人。QQ中再验收消息、记忆和本地工具往返。

扩展代码更新后在扩展管理页点击重新加载，再重新打开专用临时Chat并确认。扩展配对保留；页面登录由浏览器自己管理。

## 隔离、工具与数据

DSH依旧保存各QQ身份的会话并自动检索Hy Memory。每次请求重建专用临时Chat，将本次身份允许的上下文送入；不把账号网页历史或其他QQ身份的对话当作上下文。临时模式未确认时拒绝领取请求，避免ChatGPT账户记忆干扰私聊/群聊隔离。

本地工具由DSH执行。网页模型通过带本轮随机标识的JSON请求DSH允许的工具，DSH执行后将结果送回下一轮。工具名不在当前允许列表时拒绝。网页原生工具与Work执行环境不属于这个本地工具协议。

- `127.0.0.1:8767`：本机请求队列与扩展配对，生成/读取任务必须通过认证。它不监听局域网。
- `data/chatgpt-chat/bridge.private.json`：本机owner和扩展连接令牌；不导出到Git或配置备份。
- `data/chatgpt-chat/pairing.private.json`：一次性配对码，消费后删除；15分钟失效。
- `data/chatgpt-chat/probe.json`：仅成功状态和时间，无回复正文。
- `logs/chat-ui.*.log`：服务状态，不记录提示词、正文、Cookie或账号令牌。
- 临时任务提示词/回复仅在进程和扩展会话存储中流转；不是另一个长期记忆库。

## 使用限制

需要正常浏览器、扩展和专用Chat标签页持续打开。页面结构变化、登录过期、验证码、Chat自身限制或网络故障会返回明确错误；不会回退到Work授权接口或收费API。不要通过隐藏自动化或转移登录凭证规避登录限制。

同一浏览器串行生成；等待上限150秒，最多6个待处理请求。模型插件0.2.2把发送到网页的上下文控制在10万字符以内：按完整用户轮次省略最旧的上下文，明确标注省略消息数；保留system中的人设/规则、最新用户批次和正在进行的工具链。持久会话与Hy Memory不删除。当前轮或必需system本身过大时仍返回CHAT_UI_CONTEXT_TOO_LARGE，可用 `/new` 开始新DSH会话或缩小任务。网页完成后一次性回传正文，因此不提供逐token流式预览。

界面自动化与严格函数调用接口不同，任务工具、图片上传、重启恢复、消息突发与多身份隔离都需要在该通道实际验收。历史DeepSeek/Work验收不能替代Chat网页验收。
