# 主动轻问候

0.8.0仅保留轻问候、配对、暂停、频率、夜间免打扰和等待回复状态。问候不调用模型生成新日常，不创建生活事件、日记、故事或虚构记忆。普通聊天真实事实仍由Hy Memory处理。

开关只向已配对的主人私聊开放。关闭主动消息后普通收发继续工作。用户表示忙碌/休息或尚未回复时尊重等待和降频；QQ未确认送达不自动重发。发送成功只记录轻问候的实际发送状态，不把它提炼为用户性格或生活经历。

data/companion/settings.json保留原来的配对与频率设置，people中的互动状态仅用于等待和限流。旧worlds/journals/虚构Hy库属于本机历史数据，当前运行代码不读取、不索引。原书与虚构历史未删除；如需清理，另行明确选择数据范围。
