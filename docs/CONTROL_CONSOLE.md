# 柚柚机器人控制台 2.5.1

当前提供DeepSeek、[原生Codex](NATIVE_CODEX.md)和[Chat网页工作路由](CHATGPT_CHAT_WORK.md)。前两者共享同一身份的Hy Memory；网页工作路由只接收当前任务和附件，跳过柚柚记忆。

原生Codex页区分账号检查、临时模型探针、实际QQ回合结果，并显示各自时间。实际回合失败时显示安全错误码、失败RPC方法和数值状态，顶部状态徽标也提示“Codex对话异常”。线程占用恢复成功后显示保留历史续接的时间；普通聊天仍使用持久线程。

桌面双击“柚柚机器人控制台”。侧栏分为概览、对话模型、主动消息、群聊设置、人设与回复、生图与形象、运行日志、备份与导出。深色界面支持窗口缩放，较长的设置页可以滚动。

## 日常使用

- 概览分别显示QQ聊天、长期记忆、主动分享，提供启动、关闭、重启、刷新状态和载入配置。状态约7秒检查一次；启停与查询在后台执行，等待时仍可查看页面。
- 对话模型提供DeepSeek、原生Codex和Chat网页工作模式。Codex先刷新连接、验证模型；Chat网页先确认Edge专用工作标签页并做真实回复验证。“在Codex查看聊天”打开记忆工作目录，按页面给出的“柚柚QQ · …”名称查找历史。切换保留原路由配置和记忆。
- 主动消息支持开关、分享节奏、每日上限和夜间分享。保留已经配对的私聊身份与等待回应规则；自定义频率可以保持原值。
- 群聊设置显示与QQ命令一致的短编号，可加本机群备注，分别调整群友模式和普通插话频率。尚未绑定的群不能在此绕过绑定直接开启。群消息权限仍需在QQ端授权。
- 人设与回复支持人格提示词和私聊流式输出。保存后顶部出现“重启以应用设置”；选择合适时机重启即可。人设提示词负责表达风格，角色固定身份和世界设定仍在独立的fiction-canon.json中管理。
- 运行日志提供四种输出/错误日志，最多显示最近200行和64K字节，可自动刷新或复制。日志写入时仍可读取，已知本机Secret、Token及Bearer值会遮蔽。
- 备份与导出支持配置ZIP和真实用户长期记忆JSON。配置ZIP不包含Secret、Token、DSH登录、聊天正文或记忆数据库；仍可能含身份分区信息，只保存在本机exports。记忆JSON复用既有导出器，会短暂停止服务后恢复，执行前会说明并确认。角色生活情景不在该JSON内。

## 保存修改

生图页支持总开关、日常配图、固定形象、日常最短间隔/每天上限、手动每天上限、生成超时，保存后动态生效。任务每7秒刷新，显示原正文、状态、失败原因，可取消未发送任务、预览已完成图片。发送未确认时只有人工确认后才能重发现有图片，不会自动重复调用生图。“分享一条日常配图”仅尝试已有、未分享且已核对的配图日记，继续服从暂停、静默、等待回复和限额，没有合适条目时不会凭空生成剧情。配图说明见CODEX_IMAGES.md。

配置ZIP也包含生图设置、固定外貌档案及三张参考图，均只保存在本机。不包含任务nonce、Codex登录与配对状态、任务正文或历史生成图片；参考图请随私有备份迁移。

修改后侧栏会显示圆点。点击本页保存，或在人设、主动消息、群设置、生图页按Ctrl+S。底部显示操作进度、成功或错误信息。切换未保存的群、重新载入、关闭带未保存修改的窗口时会提示。

配置保存会检查版本；如果QQ里的命令或其他程序已经改动相同设置，会要求重新载入，避免覆盖新值。保存保留配对身份、运行统计及未知扩展字段，并在本机保留旧配置备份。群消息运行统计可能同时更新，保存会读取最新记录并短暂重试；它不是跨进程事务锁。

关闭控制台窗口会保留服务当前状态。若有后台操作尚未完成，其结果仍写在本机；重新打开后刷新状态即可确认。服务就绪依据受管进程、QQ上线日志和记忆健康接口，不代表QQ用户已读，也不保证外部模型服务永远可用。

## 本机文件与维护

- robot-control.ps1：WinForms界面、单实例、未保存状态和异步任务轮询。
- control-worker.ps1：独立后台进程，执行既有受管启停、健康查询和导出，结果存入私有.run/control-console/jobs。
- control_settings.py：安全配置快照、版本检查、原子替换、备份与日志遮蔽；使用现有PyYAML和personality_config的YAML1.2解析规则。
- 群备注位于data/control-console/preferences.json；备份位于.run/control-console/backups，重启提示位于.run/control-console/restart-required.json。均不提交Git。

ChatGPT提供方额外使用随本地安装包捆绑的JOSE 6.1.3验证账号授权，不要求单独API Key。桌面脚本面向Windows PowerShell5，必须保留UTF-8 BOM。重建入口运行create-control-shortcut.ps1；不要运行旧的双入口生成脚本。

部署控制台更新时只复制控制台源码及说明，不能用仓库personality.md或模板覆盖用户在本机编辑过的人设和运行配置。更新前可备份旧控制台；停止或重开控制台无需重启机器人。

本次隔离副本检查覆盖配置保存、冲突拒绝、字段保留、YAML off语义、日志遮蔽和配置备份；实际机器检查覆盖后台Status/Snapshot/Logs及真实界面。未在此次升级中实际停止或重启服务、导出私人记忆。详见control-console-verification.json。
