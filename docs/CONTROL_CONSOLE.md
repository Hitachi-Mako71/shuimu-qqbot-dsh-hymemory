# 柚柚机器人控制台 2.7.0

桌面统一入口由robot-control.ps1提供；control-worker.ps1在后台执行耗时操作，control_settings.py执行版本冲突检查与原子保存。

页面：概览、对话模型、主动消息、群聊设置、人设与回复、生图与形象、运行日志、备份与导出。

阅读书房、书籍导入/续读/阅读导出、日常自动配图和分享日记配图按钮均已删除。主动消息页面仅管理轻问候。生图页仅保留总开关、固定形象、手动次数限制、超时、任务查看与取消/预览/人工确认重发。

现有账户授权、模型路由、群绑定、人设的其他自定义内容、真实聊天记忆及服务启停机制保留。关闭控制台窗口保留服务当前状态。修改人设和回复显示需按提示重启；PowerShell5脚本须保留UTF-8 BOM。

日志保持共享读取和凭证脱敏；不会把Secret、Token、登录信息或完整记忆回显到界面。配置备份与记忆导出保存在本机exports，不随Git上传。
