# 群友模式（当前0.5.4）

让水木在已授权的群里接收普通群消息，看到合适话题时简短接话。不需要每条都@，也不会把每条消息变成一次Agent任务。默认每个群关闭，开关、缓存、频率和统计按群独立。

## QQ端前提

在目标群水木的机器人设置中，打开接收全部群消息/允许参与群聊的选项，实际名称以QQ客户端为准。该项控制平台是否下发 `GROUP_MESSAGE_CREATE`。应用开关无法代替QQ平台权限，也不能读取机器人进群之前的聊天历史。

已安装的腾讯官方SDK同时处理 `GROUP_AT_MESSAGE_CREATE` 与 `GROUP_MESSAGE_CREATE`，原来的DSH插件在mentionGate拦住非@消息；本版本在该位置加入按群的参与策略，没有改成所有群消息都调用Agent。

## 启用和关闭

1. 主人在已配对QQ私聊发送 `开启群友模式`，取得10分钟有效、一次性的绑定码。
2. 到目标群@水木，发送 `开启群友模式 绑定码`。绑定到当次群和群内操作者，不假设私聊OpenID等于群成员OpenID。
3. 收到开启确认后正常聊天。说到水木、适合参与的话题或有意义的问题时，她会看近期聊天，自行判断是否接话。
4. 本群任何成员可说 `关闭群友模式`，立即停用该群的自动接话、取消尚未开始的发送并清空群友模式缓存。@她仍走原有对话。

| 消息 | 可用位置和效果 |
|---|---|
| `群友模式状态` | 私聊：列出观察到的群编号和接收/接话状态；群里：直接查看本群，无需@ |
| `开启群友模式` | 主人私聊生成绑定码；已经绑定的群内操作者可在群里@重新开启 |
| `开启群友模式 G编号` | 主人私聊直接开启已观察到的那个群 |
| `关闭群友模式 G编号` | 主人私聊关闭指定群 |
| `群友频率 G编号 安静/正常/活跃` | 主人私聊调整指定群 |
| `群友频率 安静/正常/活跃` | 绑定的群内操作者在群里调整 |
| `群里安静十分钟` | 已开启的群内任何人临时暂停自动接话；不影响@回复 |

未绑定的人不能在其他群凭一句命令开启旁听。主人私聊按本机已配对身份校验，绑定码只允许一次、只绑定当次群。关闭后再次启用应由绑定者@或由主人私聊控制。

## 接话节奏

| 档位 | 两次主动接话最短间隔 | 滚动一小时上限 |
|---|---|---|
| 安静 | 3分钟 | 4条 |
| 正常（默认） | 90秒 | 12条 |
| 活跃 | 45秒 | 24条 |

0.5.1起收到消息后使用固定约0.8秒窗口，合并一小段聊天再判断，后续消息不无限重置等待；普通零碎聊天通常至少积累3条才考虑，叫水木/公主或有意义的问题可以提前考虑。明确叫柚柚/水木/公主时，每成员至少间隔5秒、群发送至少间隔1秒，每群滚动一小时最多60次；不同成员的呼唤分别排队，冷却延迟处理，不占上表普通插话配额。队列最多20项，最长保留120秒。模型可决定不回复，因此上限不代表固定发送频率。更多见[回复速度](RESPONSE_SPEED.md)。

不主动插入别人被@的问答，过滤SDK标记的机器人回声并做近期文本去重，没有新群消息不定时自言自语。@水木时取消尚未生成的接话，优先原有正式对话；关闭或暂停、出现新的@对话，旧候选会被放弃。普通插话在模型判断期间出现新消息时，最多允许在10秒内接上原话题；明确成员呼唤不会只因另一成员打招呼而取消。QQ已在发送中的请求不能保证撤回，不重试不确定的发送。模型或QQ异常后独立退避15秒；用户安静十分钟另行保存。普通文字不再按JSON强制解析，坏格式不触发全群五分钟静默，状态不假报成功。详见[可靠性修复及实际验收](GROUP_RELIABILITY.md)。

## 记忆和工具权限

- 最近30分钟、最多30条短消息缓存于私有 `data/companion/groups/rooms`，按Bot+群哈希隔离。约每5分钟清理过期正文；重启会按时间过滤并继续清理。
- 群成员使用按群派生的稳定别名，避免把多人说的话当同一人。缓存仍属于真实聊天资料，不放入Git和源码包。
- 接话只检索本群Hy Memory命名空间。不会检索主人的私聊记忆、私聊日常、其他群或Codex记录。
- 旁听内容作为短期资料，不逐条提炼成长期偏好。需要长期保存时，@水木使用原有“记住”“查记忆”“忘记”控制。
- 自动接话只调用DSH现有文本模型，不提供任务工具、文件工具或电脑操作。图片分析、长任务、正式命令应@水木，继续使用原来的DSH会话和权限设置。
- 所有模型输入仍经过本机凭证值遮蔽，但不应把凭证发到QQ群。

## 数据与观察

`data/companion/groups/registry.json` 保存按群开关、操作者、短期绑定码哈希、接收计数、发送回执计数和退避状态；`groups/rooms/qq-哈希.json` 保存短期聊天、最近判断时间和滚动限额。

“全量群消息”计数表示收到了GROUP_MESSAGE_CREATE事件，并非QQ授予读取所有历史的权限证明。“@事件”表示GROUP_AT_MESSAGE_CREATE；全量模式里@也可能通过GROUP_MESSAGE_CREATE到达。“主动接话成功”仅表示QQ发送接口接受，不代表成员已读。

本次只做本地实现和部署；未新增/运行应用测试套件。QQ群端的实际开启、接收和发送应以本机运行记录及用户反馈为准，不把SDK支持或进程上线当成完整真人验收。GitHub公开仓库是否同步以当次用户授权为准。
