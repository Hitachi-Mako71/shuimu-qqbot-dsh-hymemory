# 阅读书房（配套0.7.1／控制台2.6.0）

## 顺序

本机导入原书 → 按PDF页与字符位置切段 → 加载保存的书签 → 模型只读下一段 → 核对原文证据与感悟 → 原子保存笔记/整体理解/书签/Hy写入队列 → 按主动消息规则分享。

文件提取是本地预处理，不是模型阅读。模型不会获得原PDF、路径、未读正文或一次性整本书。
默认每段最多2400字符、每45分钟自动续读一段。手动“继续读书”只请求下一段。同一段请求幂等，重启或网络失败后不跳段。

## 数据与完整性

阅读目录：`data/reading-workspace`，与`data/memory-workspace`聊天任务目录相互独立。目录内有AGENTS、README、inbox、library、notes与hy-memory。

- 原书按SHA256标识；同书重复导入不重置书签，不替换原文或已读笔记。
- 每个字符属于一个连续片段，片段附PDF页码、页内起止位置、内容哈希。无法提取的扫描页会阻止导入，不静默跳过。图像封面只能经人工确认后排除。
- SQLite是权威账本，启用WAL；笔记、当前梗概、进度、索引待办同一事务提交。模型不能直接改数据库和书签。
- 所有逐段摘要、感悟、短原文证据、前文关联、未解问题、当时整体理解版本永久保留。整体理解更新不删除旧笔记；每8段保留一次阶段快照。
- 后续阅读提供当前梗概、相关旧笔记、最近笔记和阶段快照，支持呼应、修正理解。书中情节、读者理解和仍未解的问题有明确区分，不拿预训练知识补写未读情节。
- 原文短引文需逐字匹配当前片段及页码，前文关联只能引用实际存在并已提供的笔记ID。独立模型再检查事实、进度、关联及是否编造读书活动；未通过不推进。
- 语义核对不能保证模型绝不误解文学内容；原文锚点与历史版本用于回查、更正。

## 记忆边界

阅读笔记通过Hy Memory公开`add_extracted`接口写入`data/reading-workspace/hy-memory`；collection、agent、source与真实用户事实、虚构生活分别隔离。沿用相同QQ身份命名空间，两条对话路由共享。独立子进程关闭自动合并，保留完整已核对的笔记；每条经SDK get回读后才标记done。服务不可用时本机笔记仍保留，持久队列重试。

阅读感悟不变成用户事实、不改底层人设。群不读取私聊书架。书籍和全部私人数据不入Git。
旧版虚构日常的读书故事保留原记录，但不是真实书源；不倒填书名、原句或阅读进度。

## 分享

读完一段不强制发送。已有主动消息开关、夜间安静、小时/每天上限、最近聊天与等待回复规则照常生效。发送候选只取已经保存的真实笔记，正文注明书名和PDF页段。
QQ回执确认后登记sent；网络结果不明确时保留笔记并标记uncertain，不自动重发。积压笔记全部保留，只分享最新一条，避免补发一串旧感悟。
虚构日常、轻问候和群普通接话不能创作新的读书经历。

## 使用

控制台“阅读书房”：选择PDF/TXT/Markdown、填写书名与作者、导入、查看进度、续读一段、暂停/恢复、导出全部笔记。

QQ私聊：

| 消息 | 效果 |
|---|---|
| 书架 / 读书进度 | 书名、段数、PDF书签、Hy确认数量 |
| 继续读书 / 继续读书：书名 | 后台读下一段，完成前不推进 |
| 暂停阅读 / 恢复阅读 | 切换后续自动阅读，当前一段先保存 |
| 读书感悟 | 查看已保存的最近感悟 |
| 查读书记忆 关键词 | 从当前身份的完整阅读笔记检索 |

源书跨电脑恢复：先停止本项目服务，备份整个`data/reading-workspace`，包含SQLite/WAL、原书与Hy目录；不要仅复制当前梗概。控制台阅读JSON保存全部笔记与来源，通用记忆JSON也新增reading分区，但均不包含原书全文。

## 0.7.1 实际运行与引用编号

当前提供方按用户要求恢复deepseek-account/deepseek-flash。实际已逐段完成《浮躁》的前两段，书签到PDF第9页附近，两条笔记均通过独立核对与Hy SDK get回读。尚未读完整本书，阅读会按45分钟节奏继续。

DeepSeek输出不能可靠地逐字抄录所有引文。原文现在带程序生成的引用编号，模型只选编号；程序按当前片段回填原句、页码和字符位置。未知编号或语义核对失败仍不推进。长度/数量不合约束时只允许一次同段格式修正。旧笔记和错误候选不被当作新阅读。

聊天自动获得最近阅读的紧凑上下文，省略书名的追问也能衔接；明确讨论真实书籍时跳过虚构读书回忆。普通聊天只带最近一条与短整体理解，避免重新堆入长阅读历史。

本轮16项阅读持久化/作用域/拒绝与修正检查、3项阅读聊天衔接、3项原QQ记忆、15项旧虚构回忆检查通过，共37项；未以模拟替代原书实际阅读。控制台PS5后台ReadingStatus及已安装QQ读取函数已取得真实数据。QQ设备收到主动感悟仍受用户开关/等待/安静时段限制，不等同已经真人验收。
