# V2.0 近期连续原话接续

产品 2.0.0；本地插件 0.13.0；证据库 schema 3；删除账本仍为 schema 1。文字模型只使用原有 DeepSeek，保持账号、模型、人设与群绑定。保留独立 Codex 生图。

## 能力与边界

新会话首轮从本身份证据库选取近期连续双方消息，按照真实角色、发言者和落盘顺序生成一次历史转录。只使用有来源的用户原文和已被平台接受的助手正文；不包含草稿、拒绝/未知发送、管理命令或其他身份。转录不是当前用户指令，助手历史不代表用户认可或现实事实。

DSH 的 pre-step 只接收用户角色输入，不能在此入口可靠重放任意助手与工具消息，因此采用路线图允许的明确历史转录，而不伪造原生助手/工具消息。正文以 JSON 字符串保留 Unicode、换行和原角色，可逐字与证据库对照。恢复不发 QQ 消息、不重跑旧工具，也不触发重新提炼转录。

每个原生会话只初始化一次。持久初始化记录和实际原生消息共同判断是否已提交，正常重启不会重复加入；已存在的同会话原生尾部不重复恢复。未真正提交而中断的准备记录可以重试。/new 后保留 QQ 身份，下一条正常消息可恢复上一会话近期原话。

保留原生主动压缩、压力压缩和溢出重试。已经提交的转录在压缩后不会反复重新展开；原生摘要继续管理更早历史，磁盘证据不会因压缩删除。近期原话并非永久钉在模型窗口内，极端压缩后不能承诺逐字记得；需要重新建立有界接续可在恢复开启时 /new。无限历史问答与历史回源留到 V2.1。

## 预算与降级

读取当前路由适配器公布的 contextWindow 和输出上限；根据实际组装的 system prompt、工具模式、动态上下文、待入站消息及原生历史压力计算剩余空间。保留输出预算、4096 安全余量和至少 15% 窗口余量。恢复上限默认 8192、32 条，并限制不超过窗口 15%；可配置上限在 512—16384、2—64 之间。

当前 DSH 原生计数器采用固定字符密度，会低估中文。新增恢复计费取原生估计与 UTF-8 内容字节上限的较大值，因此实际恢复文本通常比“8192 token”标称值更短。记录明确标为估计/保守上限，不冒充服务商实际计费 Token。已有原生压力与本轮组装再保守相加，宁可少恢复。

只选择完整消息，不截断后声称原文完整。遇到超长最新消息、已删除跨度、当前会话已有原文或达到预算就停止向前选择，不跳过长消息去拼更早片段。单次最多查看最近 128 条候选，未加载范围不做历史首次判断。图片和附件正文不在此版重放，已归档的文字说明仍是当时文字。

容量不明、无输出预留、预算不足、记忆服务/证据存储异常时不加入恢复内容，普通原生聊天继续。工作模式、未授权群与关闭原文采集时不恢复。删除清理中、版本过期、身份错误则阻断旧上下文，不能以普通降级放行。

## 开关、审计与删除

- `QQBOT_RECENT_CONTEXT_ENABLED=true`：默认开启有界恢复。
- `QQBOT_RECENT_CONTEXT_TOKENS=8192`：恢复保守预算上限。
- `QQBOT_RECENT_CONTEXT_MESSAGES=32`：消息条数上限。

修改本机环境配置后重启服务。关闭开关后停止新注入；此前已提交的转录是原生历史的一部分，/new 可获得不再注入的新会话。关闭扩展不删除原文和初始化记录。

证据库新增 context_initializations 与 context_requests。前者存来源编号、内容哈希、预算和准备/提交/跳过状态；后者存实际请求哈希与消息编号、系统/动态快照哈希及恢复消息可见性，不另存正文。原生 DSH 日志保留实际输入，可核对旧动态快照是否仍在当前请求。没有把历史快照隐藏成“模型看不见”；已存在的动态上下文也不被本版重写。

恢复的用户来源加入本轮来源链，工具和发送继续执行 V1.3 隐私守卫。物理删除时清理本身份上下文初始化/输入元数据与原生会话副本，其他身份保留。恢复旧备份仍先应用当前权威删除账本。

## 迁移与回退

只新增两张元数据表，证据库由 2 升到 3，旧原文不改写，旧摘要不补成原文。部署前停服备份原文数据库，离线更新本地插件，再恢复服务。未变更 DSH、Hy 或模型依赖版本。

功能回退先关闭恢复开关，保持支持 schema 3 和 V1.3 删除屏障的程序；不要直接运行旧插件或倒退删除账本。需要二进制回退时使用支持当前 schema 的向前兼容修复包。

## 验证记录

专项使用固定 DSH 的真实消息构造器、Session 表面投影/重放和原生 Token 估计器，模型目录返回值为合成值，不发付费模型请求或自动 QQ 验收消息。检查 /new 接续、原文 Unicode 逐字一致、角色/身份、重启重放、原生表面压缩替换、溢出重试相同请求、预算不足、长中文、动态快照可见性、工作模式与删除屏障。

压缩和溢出专项只验证本地会话替换/重试边界，没有声称跑过真实服务商溢出或真实 QQ /compact。实际 QQ 发言、正常重启后续聊、主动压缩后续聊和完整活跃周期另行验收。

调试：首次专项发现固定 DSH Session 没有 events 属性，改用公开 deriveMessages 与持久初始化记录，避免同步扫描全日志。原生压缩替换夹具需声明 sourceEventSeqs，补齐夹具后通过。独立身份拒绝检查先失败，收紧异常降级后通过。换真实计数器后长中文边界失败，确认固定四字符估计原因，补字节上限后通过。未向生产部署失败版本。
