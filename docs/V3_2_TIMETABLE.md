状态：V3.2.0 / 本地插件 0.17.0 已部署。136项JavaScript及19项Python部署前检查通过；安装后50项课表、4项生命周期检查再次通过，服务健康。真实课表及QQ验收待触发，详见 `v3.2-deployment.json`。本版沿用 V3.0 时钟，不恢复 V3.1 阅读。用户暂时没有实际课表，因此生产不预置示例课程。

## 使用流程

在 QQ 私聊发送“课表模板”，会在本身份工作目录生成 `课表导入模板.csv`。可以请求机器人发送这个文件；生成文件不代表附件已发送。请修改示例日期、时区、教学周、节次与课程，然后从 Excel 另存为 **CSV UTF-8**，上传到同一个私聊。

发送“预览课表：文件名.csv”，检查学期、节次、课程、例外和冲突。每页最多显示8条记录，使用“课表预览：2”等命令查看完整候选。核对后，发送预览回复中的“确认课表：确认码”；确认码十分钟有效，仅属于当前私聊且只能用一次。新预览会替换旧确认码；CSV在预览后改变时拒绝提交。

确认替换整个当前课表并保留上一修订；它不是逐行追加。“回退课表”先预览上一修订，确认后生成更大的修订号，不倒退计数。“清空课表”同样需要确认，会清除当前和上一修订，保留上传CSV及聊天原文。清空不会撤回原有平台消息。

查询命令：`课表状态`、`今日课表`、`明日课表`、`本周课表`、`下一节课`、`课表日期：2026-09-01`。下一节只包括尚未开始的课，并返回距开始的真实秒数；当前已开始课程仍可从当日课表看到。复杂问法可由 Agent 调用 `qqbot_timetable`，但模型没有确认、回退或清空的写入工具。

## CSV 契约

仅支持不超过128 KiB、400行记录的UTF-8 CSV，可带BOM。允许正确转义的逗号、双引号和单元格内换行；列可重新排序，但不可缺少、重复或新增以下列：

```text
类型,编号,名称,日期,结束日期,总周数,时区,星期,周次,开始节,结束节,开始时间,结束时间,地点,教师,原日期,原课程编号,夏令时选择,备注
```

| 行类型 | 必填字段与规则 |
|---|---|
| 学期 | 只能一行；编号；日期填教学第1周的周一；总周数1至53；明确IANA时区，如Asia/Shanghai；名称可选 |
| 节次 | 编号为1至24；开始时间、结束时间为24小时HH:mm；同日，按节号递增且不重叠 |
| 课程 | 唯一编号、名称、星期1至7、明确周次、开始节及结束节；地点、教师、备注可选 |
| 停课 | 唯一例外编号、原课程编号、原日期；须对应原课表发生日期 |
| 补课 | 唯一例外编号、日期；引用原课程时继承未填写的名称、节次、地点和教师；独立补课必须填名称和起止节次 |
| 调课 | 唯一例外编号、原课程编号、原日期、新日期；可同时修改节次、地点、教师；原发生实例被取消 |
| 假期 | 唯一例外编号、日期，结束日期可选；范围不倒置且不超过366天；暂停普通循环课程 |

编号仅支持1至48位字母、数字、下划线和横线。日期为1900至2199年间的完整有效 `YYYY-MM-DD`，学期全部日期也须在此范围。常规课程不超过200条。不能省略节次中的中间节；不支持跨午夜节次。无关列若填入内容会报错，不静默忽略。

周次支持 `1-16`、`1-16单`、`1-16（双）`、`单周`、`双周`，以及带双引号的列表 `"1,3,5-8"`；不能超出学期周数。时区不从城市、VPN、机器或旧记忆推断。学期时区由本次导入确认，不随会话时钟设置改变。

例外优先于循环：停课/调课取消原日期，补课和调课的新安排可落在假期或学期范围之外。时间冲突保留并明确提示，不自动选择一门或覆盖另一门。精确日期、星期和教学周由程序计算；不推断实际到课。

IANA时区缺失时刻不顺延，重复时刻不自动猜测。可在课程或补课/调课的“夏令时选择”列明确填写“较早”或“较晚”；仍不存在或区间不合法时给出异常。下一节遇到未确定的相关时刻会要求澄清，不编造倒计时。

## 权限和数据生命周期

本版只提供私聊课表。每个私聊使用服务器身份派生的canonical namespace，模型不能传入任意身份；群聊不能读取或设置私人课表。文件导入仅访问本身份工作目录，不读取任意桌面、其他私聊或服务端文件。当前已下载附件优先于工作目录中同名的旧模板；多个同名上传要求明确选择。

权威状态保存于受限的 `data/timetables/qq-<hash>.json`，包含当前、上一修订、带期限候选及来源文件名/相对路径/SHA256/版本。原始CSV保留在本身份工作目录。文件采用临时写、fsync及原子rename；提交持有现有删除权威的事务锁，并重新核对删除版本。没有新数据库或数据库schema迁移。

逻辑忘记记忆不会取消已确认的现实课表。物理删除原文的预览会明确告知：本身份整个课表、上一修订及候选也会被清除，上传CSV随原有工作目录清理。其他身份不受此项清理影响。恢复旧备份同样应用当前删除权威；旧课表文件若版本落后于已生效的物理删除，读写均被拒绝。

完整基线原有data扫描覆盖课表目录；新版本恢复必须继续使用当前删除权威，不能把旧二进制直接用于课表数据。物理删除维护不读取Codex聊天，不改变其独立生图路径。课表控制命令保存原文证据，但不进入长期记忆提炼；语义召回不能改写权威课表。

## 边界和开关

`QQBOT_TIMETABLE_ENABLED=false` 关闭命令和工具。缺省开启；没有课表时返回未配置，不填充示例。普通闲聊不自动加载课表，不产生定时快照、后台任务或主动QQ消息。

本版支持CSV，不支持XLSX、ICS、截图OCR或学校账号接入。CSV可由Excel导出，不直接解析工作簿。真实课表适配待用户提供文件后进行；本版不创建本地待办、提醒、投递任务或日历同步，这些留给后续版本。

安装、相关检查、备份及健康结果见 `v3.2-deployment.json`。程序合成验证与真实QQ上传/收发验收分别记录，不能互相替代。

## 部署回退约束

优先关闭QQBOT_TIMETABLE_ENABLED。若仅撤回插件到0.16.0且仍保留课表文件，必须保留本版memory_lifecycle.py中的课表删除适配器及受限目录初始化，避免旧代码漏清理课表。不能盲目恢复整套旧代码或旧删除账本。当前备份覆盖代码/profile，不是完整数据库备份。
