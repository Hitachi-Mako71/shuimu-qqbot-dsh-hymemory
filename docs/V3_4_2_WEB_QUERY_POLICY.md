# 联网分类与完整查询规则

V3.4.2 / 插件0.21.2已安装，保留账号、人格、父母关系、课表、控制台、群节奏和刚导入的原生会话。本次不重置会话、不重提炼记忆、不自动向QQ发送验收消息。

| 问题类型 | 处理 |
|---|---|
| 陌生选手/人物ID、哪个游戏、国家和战队等不确信的公开事实 | 直接搜索核实，问题本身就是查询请求，不先询问是否联网 |
| 当前任职、转会、最新版本、天气、赛程、价格、时效政策等 | 优先核实新资料，区分当前与过去 |
| 明确提供网页让她阅读 | 读取网页，区分原文、摘要和失败页面 |
| “查一下”“继续查”，已有主题 | 从当前引用和近期对话提取公开主题继续查；确实缺少主题才问具体澄清问题 |
| 普通闲聊、情绪支持、翻译润色、给定材料总结、计算与一般代码推理 | 先直接完成，不机械联网 |
| 我们上次聊过什么、个人偏好、约定、查原话 | 只查同身份记忆/原文；明确历史证据请求仍禁止外部工具 |
| 课表、时钟、群成员@ | 沿用对应本地工具 |
| 明确不要联网 | 只用已有知识和材料，不知道的部分明确说明 |

一次公开查询先对齐用户问的全部字段，例如游戏、国籍/地区、当前或当时战队。已有部分资料时继续补查缺项，不反复问“需要继续查吗”。单页验证码或403可换队伍官网、赛事官方名单等来源，不绕过验证码；连续两轮搜索或三个页面仍无新增可靠依据就停止，并逐项标明未核实项。

赛区不等于国籍，现役不等于曾经效力；相近拼写/别名须核对，不能仅因名字相似就认定为同一人。保留本轮实际URL，搜索摘要不能冒充网页原文，未成功调用工具不能说查到了。不把私聊、群原文或账号绑定整段发给搜索引擎。

分类函数是透明的轻量提示，不声称理解所有自然语言；普通未@的择机插话继续原有有限旁听路径，不自动开放工具。实际@或叫名字进入完整对话后使用这些规则。也修正了“以前Faker在哪队”被当成QQ历史检索的问题；明确“查原话：...”仍只读原证据。

313项源码检查、161项实际安装检查通过；7项真实DeepSeek合成工具选择检查通过。检查显示：截图式问题与已知主题续查直接选择web_search，缺国籍/战队时继续调用查询；离线、翻译、情绪聊天不选择搜索。工具资料为隔离合成数据，本轮没有实际核实截图中的选手资料，也没有真实QQ收发验收。

原网页安全测试的间歇超时查明与IPv6检查前的RFC7050 ipv4only.arpa探测有关。仅在测试夹具替换DNS发现响应，继续执行真实原生地址校验和同一拒绝断言；生产公网、私网、删除与身份边界原样保留。40个安装文件与源码一致，官方补丁和原生会话路由哈希不变。

当前在线状态：已通过本机授权接口刷新二维码，用户确认扫码登录；实际小号身份、两个目标群及QQ与记忆服务均已核对在线。刚导入的原生会话路由保持原样。
