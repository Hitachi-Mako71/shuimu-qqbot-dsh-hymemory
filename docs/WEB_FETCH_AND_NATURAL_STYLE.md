# 网页跳转与自然称呼（插件0.19.2）

新增QQ作用域tools/execute恢复器，只处理原生WEB_REDIRECT_BLOCKED。按本机原生WebRuntime的显式fetchProvider及环境回退确认选中http，缺省时只接受唯一可用HTTP提供方。使用原提供方的逐次匿名请求、IP/DNS/代理校验、正文读取与字节限制，在独立派生对象中恢复公开跳转，不更改共享提供方。最多5跳，循环、HTTPS降级、凭据URL、非HTTP地址拒绝，使用原生单次总超时并保持取消和隐私检查。内部接口固定在DSH0.2.1-rc.2，缺失时保持失败，不偷偷更换网页提供方。

失败仍是失败；HTTP403/404保留原状态。模型必须区分成功搜索、只读摘要、读取原文和失败，引用真实来源。没有搜索主题时先问要查什么。

家庭身份及账号映射完全保留；家庭关系属于后台事实，普通查询、任务和聊天默认直接回答，不在每条或一条长回答里反复称呼爸爸妈妈。明确询问身份时仍准确回答；@问候保持真实提及但不强加亲属称呼。
