# ADR 0002：回话系统分阶段接线与版本基线

日期：2026-11-02。状态：仅采用分阶段实施边界；新运行链路尚未采用。

## 依据

用户授权按《QQ Agent 回话系统工程改进执行表》最终修订版 1.1 开始更新。该附件与前一份非回话 TASK-01～19 手册是不同计划，本轮使用 P01～P18 编号，不混合状态。

## 决定

1. 先完成 P01 可重复基线；明确源码候选、安装清单与进程实际加载三种版本。未取得进程证据时填 NOT_VERIFIED。
2. 后续设计分离会话状态、参与决策、上下文构造和回复生成。A 不持有发送权限；明确指向机器人的消息保留直达路径。权限、删除屏障、候选过期和发送前检查优先。
3. 新模块逐项验收、独立回退。当前不接入 A、不调整风格、不修改生产 profile，不将新方案直接部署。
4. 不恢复旧研究脚本；模型调用、训练、真实聊天采集、线上 shadow 与灰度按各自关口另行授权。
5. 公开材料只保存脱敏汇总。源配置、聊天、进程命令行和凭证不进入基线报告。

## 方案比较

- 保持现状无记录：不扰动运行，但无法固定下一阶段基线，未选择。
- 最小只读基线工具和 ADR：保留当前行为，形成可重复证据，选择。
- 立即重构/安装候选：运行版本未核验、内容未验收，风险超过收益，未选择。

## 当前限制

2026-11-02 观察到候选为 0.22.23，安装清单为 0.22.22；这并非新发现的损坏，也不应通过自动升级消除差异。P01 的运行版本和有效配置核验尚未完成，停止后续运行接线与上线判断。参见 [P01 交接](../development/handoffs/P01.md)。
