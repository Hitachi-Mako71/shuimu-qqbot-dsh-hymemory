## 研究如何用于验收

依据 Tannen 的互动框架区分分享、玩笑与明确任务，依据 Clark/Brennan 的共同基础核验回复所需的信息和澄清。EmoCharacter 启发检查情绪变化，CHAT 启发把自然表达与意义忠实分别评分，LSM 启发观察当前发言者的节奏；这些是工程应用，未声称复现论文指标。

完整评测协议和原创开发场景保存在模块的 `research/` 下。场景包含发言者和多轮上下文；同一故事的改写属于同一场景簇，不得跨开发与未见保留集。看过并用于改进的场景不可继续称未见测试。

自然回复主要采用匿名真人偏好比较，保留平局、两条都差及评价分歧。分别评价上下文适切、对象归属、事实、情绪、人物一致、自然表达和群聊时机。程序通过、问号减少、字数减少和模型自评分都不能代替内容验收。详细研究依据见[论文与设计记录](../../research/notes/DIALOGUE_LITERATURE_DESIGN_20261101.md)。

## 本机可复核的检查

从 `app/` 执行：

```powershell
node --test dsh-hymemory-plugin/dialogue-engine/test/*.test.js
node tools/run-dialogue-validation.mjs --tag=my-isolated-check
```

第二条使用隔离合成目录和本机模拟接口，需先安装固定运行依赖。模型实验工具会使用本机模型接口，应先核对输入是合成材料，并单独记录调用成本。发布仓库不包含真实聊天、记忆、模型权重、下载语料或本机实验调用记录。

NaturalConv 仅在已确认的个人非商业研究条件下使用，遵守腾讯官方来源与不再分发限制；完整语料尚未从官方取得。Douban 发布仓库的数据授权仍待核实，目前不以完整语料开展训练。0.6B/1.7B 小模型路线仍是后续研究计划，没有训练完成或效果达标的声明。
