# 默认群疑问句问答与工具依据修复 0.22.36

## 行为

用户授权默认回复群里的疑问句。已启用群的正常、安静、自适应模式中，带问号或常见疑问表达的消息直接进入正常 Agent，不再等待旁听累计消息、A 决策或主动接话窗口；真实 @ 标记保持原值。普通陈述仍按原接话规则处理。

暂停/关闭的群、已识别机器人、明确 @ 其他成员或引用其他发言者的消息继续礼让；明确 @/点名柚柚的原有请求仍按原规则。代码、引文内的问号和 URL 查询参数不直接当成成员提问。群控制者可用“群聊节奏 疑问句回复是/否”控制该行为；开关默认是。群授权、身份分区、隐私、发送限额和回执要求保留。

## 根因和修复尝试记录

- 0.22.35 已通过真实 QQ 暴露内容失败：没有本轮搜索，却称已搜索并猜术语定义。该版领域提示未解决事实性问题；本轮继续按 systematic-debugging 追踪会话、工具及发送边界。
- 新增按当前入站重置的工具执行记录：分别记录搜索、网页读取及本地查阅的实际尝试/成功；工具完成只更新开始时捕获的当前轮对象，迟到结果不能记到下一轮。固定 SDK 的原生 Agent 循环已验证下一步提示随实际搜索更新。
- 普通和流式发送前检查相关执行声明；无实际依据的“我搜过/查到/没搜到”等已覆盖句式改为尚未核实的说明，并记录匿名 grounding 计数。保留明确否定、引文、历史说明及真实本地查阅。该检查针对执行声明，不是通用事实验证器。
- 真实 DeepSeek 加合成旧错误回答的探针仍未请求工具，继续猜定义，说明提示不能保证工具选择；新校验对该真实模型输出的只读回放已拦截。没有将探针误记为真实 QQ 或内容准确性通过。

## 提速

独立概念之外，自足的常见操作问题和简单算式也跳过可选长期召回；个人历史、指代、约定等保留原查询。群问答合并等待默认从 700 毫秒降为 350 毫秒、最长从 2000 毫秒降为 1200 毫秒。本机仅同步两个已启用群的对应覆盖项，已备份原配置；私聊等待、旁听 TTL 和静默间隔不变。

审查了固定 SDK 的原生压缩/工具裁剪接口；本版不直接截断冻结的请求或删除会话。长会话与真实网页搜索仍会影响耗时，不承诺统一秒数。

## 离线合成核验

最初 32 项针对用例复现 18 项失败；算式、真实本地查阅及活跃群引用的边界反例也先观察到失败。首次全量只剩两个旧夹具冲突：其原意分别是陈述旁听、旁听分条发送，按新默认行为改用陈述或显式关闭该夹具的问句直答，不删除实际发送覆盖。最终 44 个文件、506 项通过，失败 0。
