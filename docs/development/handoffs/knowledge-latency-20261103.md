# 独立概念问答延迟修复 0.22.35

## 真实观察与根因

用户截图对应一条真实群 @ 概念请求。入站到接受状态的出站记录为 35.301 秒；长期记忆 /search 用时 23.168 秒，原文展开约 10 毫秒；Agent 内两次模型调用及一次 web_search 共约 10.8 秒，其中搜索约 6.748 秒，没有 TRANSPORT 重试。0.22.34 这一条实际正常 Agent 群回复有平台回执，但它不验证未 @ 的旁听发送。

问题属于独立概念定义，却在回答前等待个人/群长期记忆，形成串行延迟。原提问未明确模型训练领域，实际搜索也没有带这个领域；领域澄清在回复之后才入站，不能把后来的补充算作模型早已知道的条件。新补充未 @ 机器人，且前一回复后有其他成员发言，没有进入正常 Agent；原群接话、寻址和礼让规则保持。

## 本轮修复与尝试记录

一次业务修复包含：

- 用保守的独立概念句式识别跳过可选长期召回；只处理明确完整的“什么是某术语”“某术语是指什么”“解释一下某术语”等请求，兼容平台 @ 标记。指代、个人/群历史、原话、约定、URL、长文本保留原召回路径。
- 当前消息、引用和近期对话继续保留，不改变记忆存证、提炼、删除、身份边界或实际工具权限。文件任务与 TLS 修复保留。
- 公开查询提示增加领域约束：有明确领域就带入搜索，不把其他领域结果当作目标词义，也不按搜索结果多少认定用户语境；缺少领域且歧义明显时先简短澄清。

先运行新离线行为用例，5 个独立概念请求均复现一次不必要召回；9 个需要保留检索的请求通过。修改后这 14 项全部通过，全量 41 个文件、458 项离线合成核验通过。没有修改用例掩盖失败，也没有触发两次不同生产修复失败。

## 验证范围

部署后源码、运行副本和活动 profile 的 82 个插件文件哈希一致；OneBot ready，记忆和模型代理健康检查正常。通过运行中模型代理实际调用 DeepSeek 两次，耗时 2.385 秒与 1.333 秒，均 HTTP 200；其中明确模型领域的输入没有再按消防场景回答。

这两次是没有网页工具的真实模型探针，不是实际 QQ 收发测试，也不证明术语解释已被来源核实。模型仍可能列出没有来源支持的候选词义；不把传输成功或出现预期词当作事实准确性验收。新版本的 QQ 全流程耗时、搜索领域和回答准确性仍待新的实际 @ 请求及工具结果核对，不承诺固定响应时间。

## 部署

版本 0.22.35，更新插件包、固定版本及规范化/活动 profile 锁，备份 0.22.34 后通过受管理脚本重启。私人配置、两个群的频率及参与模式没有修改；真实聊天、附件、模型探针原文与诊断日志仅保留本机 .run，不发布。
