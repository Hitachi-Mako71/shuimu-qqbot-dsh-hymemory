# 按需记忆查询 0.22.44 — 2026-11-05

## 用户要求及基线

用户要求默认关闭记忆查询，只有模型当前不知道时才补查。0.22.43 最近真实群回复总耗时 22.807 秒，Hindsight 召回 20.196 秒、主模型 1.666 秒。该轮是普通聊天，无需额外记忆。

## 行为

- conversation-policy.memoryRecall.mode 缺失、非法或不可读时默认为 on-demand；只有明确 automatic 才保留旧自动路径。普通入站长期搜索和模糊历史搜索均关闭，不能只关其中一条。
- 当前上下文已知答案直接回答；准备说不知道/不记得，且缺少当前身份的过去事实、对话或此前资料时，模型才调用 qqbot_recall_memory。没有使用“用户消息包含不知道”或“最终字符串包含不知道”的正则强制触发，避免误查引文、否定或用户自身的不理解。
- 新公开知识按网页规则核实，附件读取正文；不把任意陌生术语交给私人聊天记忆。明确查记忆、查原话等控制命令仍按用户要求执行，保存/遗忘/删除的原有授权链不变。
- 工具仅接受 query 与预设信息缺口 reason，没有身份/namespace/bank 参数。身份从当前 Agent 获取，复查群授权、工作模式、隐私版本及当前轮；返回来源追加到本轮完整证据依赖，不改当前直接入站来源。
- 每轮最多两次具体查询，同查询可复用当轮已核验结果；每次整链最多 35 秒并继承取消。空或失败诚实说明，不循环重试、不编造回忆。迟到结果不能写入下一轮；隐私变化后缓存不能再使用。
- 群旁听也默认不搜索；无工具的旁听模型缺少旧资料时保持安静，正常直接 Agent 才可按需查。既有群 SQLite 有界上下文、当前会话历史、受保护身份设定和后台提炼未作为每轮 Hindsight 查询关闭。

## 核验记录

修改前默认语义预查、模糊历史预查两项失败已复现；修改后相关 8 个文件、72 项工程核验通过，包括按需调用、空结果、次数限制、来源关联、身份拒绝、迟到结果和原生工具分发；旧召回来源过滤/预算用例改为显式 onDemand 调用，未删除其边界断言。这不是修复后的真实 QQ 测试。

另通过现有 DeepSeek 代理进行合成输入的真实模型探针：普通聊天无调用；当前上下文已有合成事实时无调用；缺少历史事实时调用一次 qqbot_recall_memory，注入合成工具结果后正确使用该事实。3/3 场景通过，共 4 次推理，未查真实记忆、未发 QQ；不能当作真人消息验收或模型永不误判的保证。
