## 修复

新增 qqbot_read_pdf：file_path/url 二选一，默认第 1 页开始、每次 5 页，最多 20 页，文字默认 40000、最大 50000。返回总页数、逐页正文、hasMore/nextPage/truncated/textAvailable；不把部分页面冒充完整论文。文字截断时用更少页面重新读取；单页极长而超过最大文字预算时仍需如实说明截断。扫描页不自动 OCR；加密文件、无效 PDF 和无可提取文字有明确结果。

本地只读取当前身份工作区字节；提取器通过固定 Python 和固定脚本运行，无 shell，stdin 输入，限制本地附件 21 MiB、公开 PDF 32 MiB、15 秒、最多两个提取任务及输出量。pypdf 固定 6.1.3。公开 PDF 复用固定 HTTP 提供方的请求、每跳地址校验、整链超时；PDF 使用独立 32 MiB 下载上限，普通网页上限保持原值；截断二进制文件不当成完整 PDF 解析。工具前后核验隐私版本，历史只读轮次拒绝调用。本轮工具依据区分本地 PDF 与公开 PDF。

提示明确附件先 glob incoming/，再调用专用工具；先核对标题、节号与页码，不能把另一个来源当成同一论文，不要求用户再开放本机命令。
