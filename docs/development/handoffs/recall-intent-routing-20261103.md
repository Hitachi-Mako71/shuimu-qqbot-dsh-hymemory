# 记忆召回意图分流 — 2026-11-03

## 基线与问题

最近 3000 条匿名运行指标中，Hindsight 召回的私聊中位数约 10.8 秒、P95 约 14.2 秒；群聊中位数约 16.2 秒、P95 约 22.9 秒。代码原先只跳过少量固定问候和独立知识查询，因此公开查询、本地任务等仍可能先等待长期记忆服务。

## 修改

0.22.41 使用现有 `queryPolicy` 分类：独立公开查询、本地任务与没有历史线索的离线任务不请求 Hindsight。若消息包含历史时间、原话、旧约定、个人偏好或群/私聊历史线索，历史依赖优先，仍按原途径召回。固定问候和上一版的独立知识跳过规则保留。

新增用例后，现状首先在“今天北京天气如何？”上复现为错误的召回决定。修改后定向本地回归核验为 12/12 通过，覆盖公开搜索、翻译、离线任务、个人偏好和显式历史依赖。该核验不是真实 QQ 测试。

## 验收

0.22.41 已部署，profile 版本与打包版本一致，召回路由文件哈希匹配，OneBot/bot 与记忆服务 ready。用户在私聊发送“帮我把这句话翻译成英文：我今天去图书馆”，真实回复为 “I'm going to the library today.”，入站到发出约 4 秒。该轮有一次主模型调用（1.927 秒），无 Hindsight `recall` 或 `memory_http` 阶段指标；真实 QQ 意图分流验收通过。部署证据位于本机 `.run/deployment-evidence-0.22.41-20261103.json`。
