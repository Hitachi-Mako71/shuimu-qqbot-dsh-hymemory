# 回复排版优化 0.22.37

## 改动

生产表达规则 `dialogue-engine/style-persona.js` 的 `DEFAULT_STYLE` 新增按内容复杂度排版的约束：

- 普通聊天维持短小纯文本，不加标题和列表。
- 较复杂的解释先给结论，再用空行按主题分段；每段只讲一个层次。
- 三项以上并列内容用项目符号，顺序操作用编号；短列表不拆散普通答复。
- 代码保留围栏与缩进；标题只用于长且多主题的内容；表格仅用于紧凑横向比较。
- 避免整段文字过长、每句话单独换行及重复结论。

包内还包含此前待部署的工具声明边界修正：本地读取成功不能替网页搜索结果背书；“没搜到”需要本轮搜索成功作为依据。这是执行声明检查，不是通用事实核验。

规则加入生产 Agent 实际读取的 `DEFAULT_STYLE`，没有改为依赖历史自然聊天 skill 文件，也没有加入发送后自动重排，避免破坏代码、引用和用户原文。
