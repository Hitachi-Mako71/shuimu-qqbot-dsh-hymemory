# V1.3 删除屏障与恢复生命周期

产品 1.3.0，本地插件 0.12.0，证据库 schema 2，删除权威账本 schema 1。文字对话仍仅使用 DeepSeek，独立 Codex 生图保留。

## 三种操作

- **导出**：复制当前有效提炼事实，不等于完整备份，也不会删除数据。
- **忘记：记忆编号**：逻辑遗忘，屏蔽对应提炼及来源的旧任务；原始聊天、工作文件和历史档案保留。完成前显示待处理。
- **删除原文：来源编号**：先预览，再用一次性确认码确认物理清理。原文编号命令只显示本身份最近八条用户记录的编号与状态，不展开正文。

在 QQ 发送“原文编号”，再发“删除原文：完整编号”；确认范围后发送“确认删除：确认码”。确认码十分钟有效、绑定身份和操作者；群里只有已绑定控制人能够确认删除。发送“删除状态”查看完成或受阻；“重试删除：操作编号”重试已经确认的受阻操作。

## 清理范围

删除确认会说明：目标用户原文及相关助手派生内容、对应提炼任务、本身份 Hy 索引、本身份整个当前工作目录、本身份 DSH 会话快照与投影、匹配的本地生图任务、受管导出，以及共用的可丢弃诊断日志。由于旧版本缺少细粒度工作文件来源，采用明确告知的整个身份工作目录清理。保留其他用户原文、分区与无关提炼任务；本身份剩余合格用户原文会重新提炼以重建索引。

权威删除账本位于 `.privacy/lifecycle.sqlite3`，独立于普通备份。确认后先提交单调递增的版本和来源屏障，再定向取消相关任务；清理过程中阻断本身份旧上下文、工具和派生写入。已获准写入的提炼会先结束，删除再覆盖其结果。旧回合不能在删除后重新提交；新会话正常工作，/new 仍创建新会话。

物理清理由独立隐藏维护进程执行：停止本项目受管服务，清理，再恢复。其他身份任务不会取消，但维护期间全机器人会短暂停顿。清理失败显示 blocked 并保持屏障，不假报完成。未知导出格式、远程/图存储、未实现的内容追踪后端需要删除适配器，不能静默跳过。

## 备份、历史档案与回退

备份不携带 `.privacy`。恢复必须提供仍在使用的同一权威账本；先核对备份原始校验，再按最新删除记录清理副本，最后才开放隔离只读检查。报告区分“备份原始校验通过”与“删除后文件已改变”，不会把清理后的内容说成与旧备份字节一致。相关 DSH 会话按本项目证据来源收录，不读取 Codex 聊天。

已停用的阅读目录、虚构日记/世界及虚构人物字段归入受限只读 `.retired`，保留原始字节，不再加载或生成。混合人物状态只去掉 life/moments/story，绑定与真实互动状态保留。旧备份和只读历史档案不主动重写，不能直接覆盖运行目录；恢复时必须经过最新删除屏障。

二进制回退不撤销删除。不得用 V1.2 或更早版本直接启动已升级数据、恢复旧索引或替换权威账本；需要向前修复，或保持相关派生功能停用直至支持当前屏障。

## 后续删除适配器契约

新增缓存或 Hindsight 等存储必须支持身份、来源编号、版本与幂等清理；写入前持有账本守卫，删除返回可核对结果。未实现适配器时禁止报告删除完成。现版只支持已固定的本地 Hy/Chroma 配置。

## 验证与限制

相关局部合成检查覆盖跨进程写入/删除竞争、跨身份拒绝、只取消相关任务、清理失败重放、原文与工作文件清理、真实本地 Chroma 删除、旧备份恢复后不复活、退役归档、会话轮换及 /new。无自动真实 QQ 消息或真实用户删除验收。

物理清理不等于 SSD 取证级擦除，也不能撤回 QQ 服务器消息、用户下载副本或 Codex 软件中既有图片。未新增 V2.0 近期原文注入或 V2.1 历史回源。

调试记录：完整快照首次暴露读取源 SQLite 导致新增 WAL/SHM；增加复现检查后改为读取一次性副本，通过。随后独立发现固定 Hy 配置字段为 enable_graph，修正适配器后通过。另以失败检查先复现并修正：旧无来源任务绕过屏障、重复旧编号清理新文件、版本会话映射吞掉 /new。目录联接检查在沙箱因权限拒绝，改用本机权限复跑通过，未修改边界实现。

## V3.2 权威课表

逻辑忘记记忆不取消已确认课表。物理删除的预览明确包含本身份整个课表、上一修订和候选；data/timetables/qq-<hash>.json及对应临时文件随删除清理，上传CSV随身份工作目录清理。旧备份恢复使用同一适配器。新课表写入持有当前删除权威事务锁并核对版本，旧快照被物理删除版本屏障拒绝。
