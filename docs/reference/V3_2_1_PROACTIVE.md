# V3.2.1 主动私聊修复

旧轮询仅在两条常量中选择，未调用模型。隔离复现三次循环、模型调用零次，末两条内容相同。

现在每个符合原有频率、免打扰和等待回复规则的周期，DeepSeek读取同一私聊最近至多12条、正文合计3600字的真实原文和最近12条主动发送记录，选择一个具体话题并输出一条短消息，也可以选择安静。不输出思考过程、不执行资料中的指令、不编造现实生活经历。

固定在场问候、相似正文和近期重复话题会被拦截。模型或上下文不可用时不发送兜底文案。生成在人物锁之外进行，用户回复不等待模型；发送前重新核对回复活动标记、原文水位、暂停/绑定/免打扰、隐私版本及限额。已有频率设置和用户数据保持原值。

发送记录先保存prepared，只有真实平台消息ID才变成accepted；明确4xx拒绝记rejected，其余不确定情况记unknown并退避。unknown/rejected不当成已接受的未回复消息，但保留内容参与去重，避免立即重试。平台接受不表示已读。

模型对新话题可以省略可选来源提示；显式声称回忆仍需有效来源。后台消息的原文关联所有实际提供的上下文来源，同一身份内把助手来源追溯到用户原文；物理删除沿既有related_ids闭包清理。后台消息不进入长期记忆提炼。没有新增长期原话缓存、数据库schema或群主动权限。时钟仅使用用户确认时区，不猜本地饭点。

新增34项主动消息检查；连同课表、时钟、身份、证据、历史和近期上下文共170项Node检查，以及19项Python生命周期检查均通过。部署后需核对实际安装字节、运行模块检查和服务健康。真人QQ收发由用户实际触发，隔离检查不代替真人验收。

本次补丁产品版本3.2.1、插件0.17.2，未启用V3.1阅读或V3.3事件功能。部署前代码/profile备份位于受限.run/releases；它不是完整数据备份，不回滚删除权威或覆盖课表数据。
