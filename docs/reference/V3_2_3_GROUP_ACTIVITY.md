# V3.2.3 群聊自定义节奏

产品3.2.3、插件0.18.0、控制台2.9.0。每个群独立保存activity设置，缺省关闭。升级不替用户开启自定义或改变正常/活跃选择，不改私聊主动频率。保存后无需重启机器人。

| 参数 | 范围 | 新配置初始值 |
|---|---|---|
| 每分钟发送上限 | 1–120条 | 6 |
| 每小时发送上限 | 1–3600条 | 120 |
| 两条回复最短间隔 | 0–3600秒 | 10 |
| 正常/安静档判断间隔 | 0–300秒 | 20 |
| 正常/安静档累计消息门槛 | 1–30条 | 3 |
| @和点名也受发送限制 | 是/否 | 否 |

0秒间隔表示不加额外间隔，分钟/小时上限仍然生效。普通陈述按累积门槛考虑，问句、呼唤等保留提前响应的既有规则。活跃模式直接进入正常对话，不使用判断间隔与累积门槛。正常模式仍可能选择倾听；发送限额不能把正常自动变成活跃。

控制台：重新打开“柚柚机器人控制台”，进入群聊设置，选群并勾选“使用本群自定义节奏”，填写数值后保存。旧窗口可关闭后重开；本次不强行关闭可能含未保存内容的窗口。

QQ群绑定管理者可以发送：

- 群聊节奏
- 群聊节奏 每分钟6条 间隔10秒 每小时120条
- 群聊节奏 判断间隔5秒 累计1条 限制点名否
- 群聊节奏 开启 / 群聊节奏 关闭 / 群聊节奏 重置

私聊主人使用“群聊节奏 G群编号 每分钟6条 间隔10秒”；编号来自“群友模式状态”。只修改给出的参数，填写数值会启用自定义，关闭保留数值，重置恢复初始值并关闭。未绑定群不能借此启用采集；普通群成员不能改数值。

发送按滚动60秒和3600秒窗口计数，在实际SDK请求前预留名额。长回复拆成多条时每条占名额；未知或失败请求也占名额，不自动重试。超额会排队，每秒读取最新设置；预计或实际等待超过2分钟的旧回复会取消，不补发陈旧内容。管理命令不受限，默认@和点名豁免，也可主动勾选限制。限额适用于文字、媒体发送及流式最终发送，流式编辑不计为额外最终消息。没有用路由次数冒充发送条数或接受回执。

计数只保存数字时间戳在既有群配置，不保存新的聊天正文、来源ID或长期事实。Node和Python共用JSON字段规范，控制台版本比较包含activity，但不包含运行计数；避免QQ修改被陈旧窗口覆盖。发送前继续遵守原文隐私版本，排队期间关闭或暂停会取消普通回复。凭证、人格、课表、私聊和删除权威保持原状。

验证覆盖104项不同Node检查、7项Python配置检查；最后发送路径45项相关检查通过，界面已在不显示窗口、不连接QQ的合成表单中核对。实际安装后还需核对新模块、控制台后端和服务健康。QQ真人新参数验收需用户实际保存数值并触发新消息，不自动替用户发测试消息。


最终部署：0.18.0及控制台2.9.0已安装。实际安装64项Node、实际生产后端7项配置检查通过，33个插件文件和2个控制台文件一致，7个官方补丁文件保持原值；服务就绪。已有群模式与自定义开关不变，未代替用户选择数值或自动发送QQ测试消息。
