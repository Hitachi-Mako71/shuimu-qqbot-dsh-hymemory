# 柚柚 V3.4：聊天策略与换号记忆核对

已安装插件0.21.0并恢复小号，原控制台2.9.0保留。原人格、父母绑定、DeepSeek路由、课表、群映射和删除权威校验未变。

## 私聊

先回应眼下的话和真实情绪；普通闲聊一到三句，复杂任务按需要展开，最多一个自然追问，不每句称呼爸爸妈妈。稳定关系按验证账号识别。新更正优先，一次玩笑、低落或临时状态不升格永久偏好。

主动检查间隔45–90分钟，每小时最多1条、每天最多6条；这是检查机会，不是保证发送。原23:00–09:00免打扰、用户忙/睡觉、等回复退避均保留。只有内容新、贴题且此刻适合才发；重复、过期、无意义问候则安静。

## 群聊

两个群保持当前活跃/正常档位，都启用自适应择机接话。观察窗口2–6秒且不会被不断重置；先检查近期自己与各成员的发言占比，再由DeepSeek判断是否有新增内容。只聊天表情、复读和别人的@对话通常不插话。不会为模拟人类而隐瞒AI身份，也不搬用狼人杀游戏里的欺骗策略。

| 当前档位 | 普通消息上限 | 实际发送最小间隔 | 判断间隔/累计消息 | 普通插话冷却 |
|---|---|---|---|---|
| 活跃 | 每分钟3条、每小时36条 | 12秒 | 8秒/2条 | 至少20秒 |
| 正常 | 每分钟2条、每小时18条 | 20秒 | 12秒/3条 | 至少45秒 |

这些都是上限与初值，不是目标发言量。直接@或叫名字仍走原完整对话/工具流程，不受普通插话等待、占比和此处自定义限额约束。控制台仍可改分钟/小时数量、发送间隔、判断间隔等。群绑定管理员可发“群聊节奏 自适应”或“群聊节奏 跟随档位”切换；主人私聊可发“群聊节奏 G编号 自适应”，G编号见群友模式状态。切回跟随档位后，活跃档恢复原逐条对话行为。

## 记忆与身份连续性

完整分页扫描3个旧分区，1,049条当前有效记忆逐条经删除屏障回读成功。1,020条带原文来源，未发现缺失或跨身份来源链接。另29条旧记录没有新原文来源，原样保留，但不自动当成现实个人事实。爸爸的私聊、每个群都仍使用旧逻辑身份；换小号没有新建空白人格或合并私聊与群。未绑定旧身份的其他用户不能凭同名继承旧私聊资料。

本次“全部召回”指全量存储可读性及来源核对，没有把整库灌进她的单轮上下文。运行时按问题检索，最多6条去重且有来源的记忆，记忆正文总计4800字内；再最多展开3条原文，总计2400字内，区分时间、发言者、更正和截断。纯问候不必查库。来源不可核对时不假装逐字记得。群插话引用的原文来源也进入既有删除闭包。

语义检索抽查9项命中6项；3项未命中不等于记录丢失，按编号回读及其来源仍存在。现有“还记得/上次/查原话：关键词”路径可进一步回查原文。不能承诺所有问题都会完整想起，也不把统计检查当作真实对话效果验收。后台提炼队列状态见JSON报告；本次没有重提炼整库、复活已忘记内容或恢复废弃鱼人设。

## 论文如何使用

以下是对本地提供文件的工程借鉴，不是对论文效果数字的复现，也没有额外训练DeepSeek。数值节奏需要根据实际群反馈调节，不能从论文直接推出全局最佳值。

| 论文 | 本轮采用/核对的方向 | 未声称完成 |
|---|---|---|
| Time to Talk（单独提供PDF，第2–3页） | 区分说什么与何时说，参考参与者发言占比，异步观察 | 普通QQ群等同Mafia实验、同样效果或游戏欺骗策略 |
| Self-RAG（第3页） | 按需检索，回答前核对相关性/支持度/用途 | 训练反思token或重训模型 |
| SEEM（第3页） | 从提炼指针回查真实原文，保留来源和事件时间 | 新建图数据库或跨身份事件图 |
| MemoProAgent（第4–5、8、11页） | 内容价值与时机分开，避免重复/过早触发 | 视频监视、GRPO训练或复现其分数 |
| TiMem（第3页） | 比较时间/层次与按问题筛选的思路，既有身份与原话层继续分开 | 构建完整五层Temporal Memory Tree |
| RMM（第3页） | 核对多粒度原话与提炼的区别 | 在线RL重排器 |
| RecMem（第3页） | 保留原文，避免把每句临时话升格稳定偏好 | 替换现有提炼器或重做全量合并 |
| Amory（第3页） | 核对真实事件组织和长期连贯性的作用 | 虚构经历、重新启用故事/日记 |
| StructMem（第3页） | 核对时间锚定与事实/关系区别 | 跨事件推断关系写回事实库 |
| MemoryAgentBench（第3页） | 检查准确检索、更正、长程连续和选择性遗忘边界 | 跑完其完整公开基准或对真实用户删除验收 |

本轮按用户提供的本地论文核对方法，私人PDF及其全文抽取不纳入公共源码。
