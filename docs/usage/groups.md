# 群聊管理

群参与和群长期记忆需要明确绑定，开关、控制者与接话设置按群保存。

## 接收消息的前提

- 官方 QQBot：在 QQ 平台和目标群确认机器人能收到所需的群事件；应用内开关不能代替平台权限。
- OneBot：目标数字群号必须同时出现在本机 `allowedGroups` 和 `groups` 映射中，QQ/NapCat 需实际收到该群消息。

## 绑定与开关

1. 主人在已配对的 QQ 私聊发送 `开启群友模式`，取得一次性绑定码。
2. 到目标群 @机器人，发送 `开启群友模式 绑定码`。
3. 收到确认后，用 `群友模式状态` 查看当前群状态。

| 命令 | 用途 |
|---|---|
| `群友模式状态` | 查看当前群或主人私聊中的群状态 |
| `关闭群友模式` | 停止本群自动参与；@回复仍按原流程处理 |
| `群友频率 安静/正常/活跃` | 授权控制者调整本群档位 |
| `群聊节奏` | 查看本群自定义节奏；带参数时由控制者修改 |
| `群里安静十分钟` | 临时暂停自动参与 |

“活跃”档与普通选择性接话的行为不同，细节见[活跃群说明](../reference/V3_2_2_GROUP_ACTIVE.md)。自定义上限与间隔见[群节奏说明](../reference/V3_2_3_GROUP_ACTIVITY.md)。

## 控制者与隐私

一个群可以有多个精确授权的控制者。群频率、节奏、时区、生图等管理入口共用本群控制权限，原主控仍保留。新增控制者通过本机群授权配置管理，不依据昵称或普通群员身份自动扩权。

本群记忆与其他群、成员私聊分开。群控制权不授予读取成员私聊记忆的能力。绑定关闭或暂停时，排队中的自动回复会重新检查当前设置。

## 疑问句默认问答

0.22.36 起，已启用群的疑问句默认进入正常问答，无需 @ 或点名，不等待旁听累计消息或主动接话窗口；真实 @ 标记不会伪造。普通陈述仍按原档位处理。明确问其他成员、引用其他发言者、已识别机器人及已暂停/关闭群保留排除规则；明确 @/点名柚柚的请求继续原处理。

群控制者可发“群聊节奏 疑问句回复否”关闭，或“群聊节奏 疑问句回复是”开启；私聊管理时在“群聊节奏”后带原群编号。发送频控及隐私约束继续有效。
