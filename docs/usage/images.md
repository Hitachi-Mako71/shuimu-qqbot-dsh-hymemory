# Codex内置手动生图

QQ发送“画图：描述”，或明确请求生成图片，由独立“柚柚·生图工作室”处理。必须使用Codex内置image_gen，不静默切换收费API。生图时Codex桌面需能接收任务；账号额度仍适用。

当前只保留手动任务。自动日常配图入口已移除，手动任务、识图、固定形象和原来的QQ回传目标保持。

控制台可设置手动生图开关、角色参考、每天手动次数、等待超时，查看/取消/预览任务。发送不确定时不自动重复生成或重发，用户需先确认QQ是否收到。

data/character/profile.json和私有参考图用于固定人物形象；不随Git迁移，新机器需通过自己的私人备份恢复。已配对私聊可请求生图；群内由当前群精确授权的控制者请求。配对、nonce、任务资料和完成文件均为本机私有数据。
