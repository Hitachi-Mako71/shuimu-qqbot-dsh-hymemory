# 记忆与原文

机器人使用 Hindsight 保存真实聊天记忆，并以独立原文证据支持近期接续和历史查询。群与私聊使用不同分区。

0.22.44 起默认先用当前上下文回答，普通消息不自动搜索长期记忆。只有缺少过往个人事实、对话或旧资料，准备说不知道/不记得时，才按需补查；查不到会如实说明。公开知识问题按联网规则核实，附件按文件/PDF工具读取。用户自己说“不知道”不会直接触发记忆查询。

| 常用命令 | 用途 |
|---|---|
| `记住：内容` | 保存当前身份的明确事实或偏好 |
| `查记忆 关键词` | 查询当前空间的长期记忆 |
| `记忆状态` | 查看记忆服务与队列状态 |
| `忘记：ID` | 对查询到的记忆执行逻辑忘记 |

历史查询只能展开当前身份的真实原文。助手曾说过的话不自动等于用户认可的事实，也不代表现实事件已发生。

逻辑忘记与物理删除不同；原文物理清理需要预览与一次确认，详见[删除生命周期](../reference/V1_3_PRIVACY_LIFECYCLE.md)。备份恢复也需要保留当前删除账本。

Hindsight 和 embedding 随服务预热并常驻；按需的是查询时机，查询本身仍可能耗时，见[资源使用](performance.md)。
