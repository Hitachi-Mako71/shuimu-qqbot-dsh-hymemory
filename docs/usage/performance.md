# 记忆常驻与资源使用

0.22.46 默认按轮次选择思考：普通请求 off；明确要求仔细复查时 high，并重读相关资料。较深思考可能增加该轮延迟，不代表整个群持续使用高档；后续普通消息恢复基线。发送“模型状态”可查看设置与本会话最近请求档位，重启后最近记录重新开始。实际服务已接受 high 合成探针，工程核验不代替真实 QQ 收发。

当前 0.22.46 默认不在普通入站前查询长期记忆或模糊历史；模型只在当前上下文确实缺少过往信息时调用按需查询。明确查询命令仍可执行，查询本身仍可能花费十几到几十秒；默认路径是否提速须核对新版本真实 QQ 收发，不能复用旧版耗时。

Hindsight 与本地 embedding 随服务启动预热并保持常驻，空闲不再自动释放。这可避免普通对话等待召回服务冷启动，但会持续占用内存；原文后台提炼和删除任务仍遵守既有队列与隐私规则。

在 `app/` 可检查接口与日志：

```powershell
Invoke-RestMethod http://127.0.0.1:8765/health
Get-Content .\logs\memory.out.log -Tail 30
```

健康接口返回只能证明该接口可达及其报告的状态，不能代替真实推理、记忆检索质量或 QQ 收发验证。实际耗用与硬件、会话长度及任务有关；旧版本延迟样本不作为当前性能承诺。

0.22.36 群问答默认合并等待 350 毫秒、最多 1200 毫秒。独立知识、操作问题和简单算式跳过可选长期召回；依赖个人历史和指代的请求继续原检索。两条真实未 @ 群问句样本：含网页搜索的概念问答 11.474 秒（搜索 5.811 秒），无搜索算式 2.635 秒；均有平台回执，样本不构成统一时延承诺。详见[验收与修复记录](../development/handoffs/default-group-questions-20261103.md)。

0.22.39 的真实私聊问候耗时约 20 秒，其中可选记忆召回 14.2 秒、主模型约 3.8 秒、发送约 0.25 秒；问候不需要旧记忆。0.22.40 部署后同一句真实 QQ 私聊约 3.4 秒：无记忆搜索，主模型 1.53 秒，发送 0.20 秒，单次模型调用。单轮样本不代表整体延迟承诺。详见[阶段分析和真实复验](../development/handoffs/greeting-recall-latency-20261103.md)。

0.22.41 按意图跳过独立公开查询、本地任务和没有历史线索的离线任务的长期记忆召回；个人偏好、明确的历史时间/原话/约定线索继续检索。真实 QQ 翻译验收约 4 秒，无 Hindsight 搜索；单轮结果详见[记录](../development/handoffs/recall-intent-routing-20261103.md)。
