# 阅读书房

从控制台“阅读书房”选择PDF、TXT或Markdown，填写书名和作者并导入。
模型每次只接收最多2400字符的新原文，附PDF页码、已读梗概和选中的早先笔记。
每段保存摘要、感悟、逐字原文证据、前文关联、未解问题和截至当前位置的整体理解。

默认每45分钟接着读一段，可暂停；“继续读书”只排下一段，不会把整本书读完。
分享经过原有的主动消息开关、频率、夜间安静和等待回复规则，不会每读一段就强制发消息。
书源未能提取文字、模型失败、出处不符、独立核对失败，都不推进书签。
扫描PDF需要先完成OCR。封面只有在本机人工确认后才能排除，不能自动跳过扫描正文。

QQ：`书架`、`读书进度`、`继续读书`、`暂停阅读`、`恢复阅读`、`读书感悟`、`查读书记忆 关键词`。
私聊与群聊各自隔离，当前书架默认属于已配对私聊，不自动向群分享原书和感悟。
